## v1.0.0 ｜ 2026-10-25 ｜ 首个公开版本

天津中德开源鸿蒙社「1024 程序员节」代码画廊：本网站对同学们提交到 [AtomGit 比赛仓库](https://atomgit.com/tsgu-osc-org/1024) 里各语言的「Hello OpenHarmony」作品直接“运行”并展示出来——并不是放一张本地执行完之后随手截的图。

整站是纯静态页面——没有服务器、没有数据库，访问者不用登录，也没有任何写操作。

线上地址：https://osc-harmony1024-gallery.pages.dev/

### 三种执行方式

| 作品语言 | 怎么跑起来的 |
| :--- | :--- |
| HTML / JS | 直接在页面的沙箱里渲染 |
| Python | 在**浏览器里**真执行（WebAssembly 版 CPython），代码不经过服务器 |
| C / C++ | 构建时执行一次，页面回放真实输出（含终端颜色），浏览器里不会跑二进制 |

### 本版包含

**新增**
- **逐帧实时输出**：终端动画类作品的每一帧都会显示出来，不用等程序跑完才看到结果
- **重播**：跑完后点「重播」就能按原节奏再看一遍，**不会重新执行代码**
- **放大**：宽屏时把卡片铺满整行，手机上是全屏查看（还能一键横屏）——长代码不用左右拖、宽的字符画不会被截断
- **示例角标**：活动前期的示例作品带「示例」标记，真实作品始终排在前面

**改进**
- 预览区改成固定高度，长代码在卡片内部滚动，卡片高度不再随内容变化
- 放大某张卡时其余卡片轻微变暗，避免旁边的作品抢走注意力
- 作品编号对比度提高

**兼容与运维**
- 提取脚本兼容 GBK 编码：Windows 下保存的中文源码不再乱码或白屏
- 定时部署加了守卫：产物和线上完全一致时跳过部署
- 同步改由 Cloudflare 定时器每 5 分钟触发一次，合并后几分钟内就能在墙上看到
  （GitHub 自带的定时任务不保证准时，只作兜底）

### 正式提交推动的两个改进

首批作品上线后，出现了未预料到的情况：

- 一份用逐帧绘制做效果的终端动画，只会显示最后完成的那一帧；
- 另一份代码有 139 行，直接把卡片顶高、连带同一排的卡片一起变形。

现在的做法：动画边跑边画，预览区固定高度、内容自行滚动。

### 已知边界

- **网页类作品放大后两侧会留白**：作品页面多为固定宽度，卡片变宽它不会跟着变宽；
- **首次运行 Python 要等运行时下载**（约 13MB），之后走浏览器缓存，再点就是秒开；
- **C/C++ 的「运行」是回放**：输出在构建时生成，代码改动需要重新构建才会更新；
- **校园网访问 `*.pages.dev` 可能有波动**。

### 卡片交互方式

1. 打开任意 Python 作品点「运行」：先加载运行时，然后逐帧点亮；
2. 点卡片右上角的放大图标（宽屏 = 铺满整行，手机 = 全屏），再点「重播」，同一段动画会再放一遍；
3. 换一份 C/C++ 作品：看到的是构建时真实执行的结果，不是前端模拟的。
