# 代码画廊 · 提交指南（面向同学）

> **这份指南面向提交作品的同学**，可以整篇复制到作品仓库 README 或群公告。
> 一句话总则：**你交上来的文件就是最终展示形态**——网站不做任何编译、不装任何依赖，
> 交什么就原样展示/运行什么。
>
> 提交方式：fork（或建分支）→ 在**以你名字命名的目录**里放作品 → 提交 PR →
> 合并后 **30 分钟内**自动出现在展示墙上。

---

## 一、目录约定（最重要的一条）

```
1024（作品仓库）
├─ 张三/                 ← 目录名就是你卡片上的作者名
│  ├─ hello.py
│  └─ README.md          ← 可选：一级标题会成为卡片标题
├─ lisi/
│  └─ index.html
├─ 王五/                 ← 一人一个目录，别共用
└─ README.md
```

- ✅ **每人一个第一层目录**，代码放目录里
- ❌ **不要把代码文件直接放在仓库根目录**——那样会读不到你的名字
- ❌ 不要往别人的目录里塞文件

---

## 二、各语言怎么交

### HTML / CSS / JS —— 直接渲染，所见即所得

- 一个作品 = **一个自包含的目录**：`index.html` + 同目录的 `style.css`、`app.js`、图片
- ✅ 必须用**相对路径**引用它们（`src="app.js"`、`href="style.css"`），网站会自动把
  它们打进页面，打开卡片就是运行效果
- ✅ 可以用 CDN 的外部资源（https 开头）
- ❌ 不要用 npm / webpack / Vite / JSX / TypeScript / Sass —— **网站不编译**，
  交 `.ts` `.jsx` 源码是不显示的；要交就交浏览器能直接跑的最终文件
- 📏 图片单张 ≤ 300KB（建议压缩后再交）；整个目录的引用资源合计 ≤ 2MB

### Python —— 浏览器里真执行

- ✅ 交 `.py` 文件，用 `print()` 输出，支持 ANSI 颜色（`\033[9xm`）
- ✅ 只用 **Python 标准库**（`time`、`math`、`random`、`turtle` 除外——它是图形库）
- ❌ 不要 `import numpy / pandas / requests` 等第三方库（浏览器环境没装，会报错）
- ⏱ 运行限时 **5 秒**，超时会被强制终止；别写死循环
- ❌ 不要读写文件、不要联网请求

### C / C++ —— 构建时编译，展示回放真实输出

- ✅ 交 `.c` 或 `.cpp` **单个文件**，用 `printf` / `cout` 输出到控制台
- ✅ 只用标准库（会自动链接 `-lm`）；同目录的 `.h` 头文件可以 include
- ❌ 不要用图形库（EasyX / graphics.h）、第三方库、多文件工程
- ❌ 不要读文件、不要死循环（超时 5 秒强制终止，卡片会显示「疑似死循环」）
- 💡 想要彩色输出？用 ANSI 转义：`printf("\033[32m绿色\033[0m\n");`

### JavaScript 单文件 —— 包一层壳直接跑

- ✅ 交独立 `.js`，用 `console.log(...)` 输出，输出会被展示
- ❌ 不要操作 DOM（没有页面给它挂）

## 三、通用规则（所有语言）

| 规则 | 说明 |
| --- | --- |
| **编码 UTF-8** | Windows 记事本默认可能存成 ANSI/GBK，交之前用 VS Code 右下角确认编码是 UTF-8，否则全是乱码 |
| **单文件 ≤ 256KB** | 超过的文件不会展示 |
| **一个目录 = 一个人的作品** | 目录里多个互不相关的文件会变成**多张卡片**，想只交一件就只放一件 |
| **写个 README.md** | 同目录放一个，第一行 `# 标题` 会显示在卡片上 |
| **命名别太野** | 目录/文件名用中文或英文都行，别用空格和奇怪符号 |

---

## 四、常见错误自查

| 症状 | 原因 |
| --- | --- |
| 卡片上代码/输出全是乱码 | 文件编码不是 UTF-8 |
| 卡片作者显示的不是我的名字 | 文件放错位置（不在第一层目录里） |
| 我的作品没出现 | 扩展名不被识别 / 文件超 256KB / PR 还没合并 |
| HTML 白屏 | 引用资源用了绝对路径，或资源没一起提交 |
| Python 报 `ModuleNotFoundError` | import 了第三方库，改用标准库 |
| 卡片显示「疑似死循环」 | 程序超过 5 秒没结束 |

---

## 五、动效支持

- HTML：页面加载动画、悬停交互、`requestAnimationFrame` 动画都支持（iframe 沙箱内随便玩）
- 控制台彩色输出：ANSI 转义码在 Python / C / C++ 里都支持
- 让输出"动起来"：Python 里 `print` 配合转义光标移动也行——但注意 5 秒上限

> 展示的是"代码真的在跑"
